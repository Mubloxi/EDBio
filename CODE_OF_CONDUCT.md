# Code of Conduct

Everyone is welcome to contribute as long as they stay respectful.

## Standards

- Be kind and constructive.
- Focus on the code and the problem.
- Do not harass, threaten, or shame people.
- Do not share private commander data or personal information.
- Accept useful feedback and explain disagreements calmly.

## Reporting

Report unacceptable behavior to the repository owner through GitHub:

https://github.com/Mubloxi

The repository owner may remove comments, close discussions, or restrict
participation when this code is not followed.
