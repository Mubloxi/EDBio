# Security

EDBio keeps data in the local Windows user profile. It may process Elite
Dangerous journal files and save planets, samples, and history.

Do not publish full journal logs or SQLite databases. They can reveal your
commander name, travel history, docking locations, and coordinates.

To report a security problem, open a private security advisory on GitHub:

https://github.com/Mubloxi/EDBio/security/advisories/new

Please include a short description, affected files or features, and steps to
reproduce the issue. Do not post secrets or private data in a public issue.
